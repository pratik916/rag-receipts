Which form factor for the demo UI?

All three ship the same engine + ablation receipts underneath — this decides what a visitor sees and how much frontend work we take on. Click one to select.

A

Full web app — Playground + Ablation Lab

FastAPI backend + polished React/Next.js frontend. Two main views: a query playground showing the route the engine chose, retrieved chunks with fusion/rerank scores, and the cited answer — plus an Ablation Lab tab with component-delta charts.

B

Streamlit app — toggles + instant metrics

Single Python codebase. Sidebar toggles flip components on/off; main pane re-runs the eval slice and redraws the chart. Fast to build, demo-able in minutes, slightly less polished look.

C

CLI + self-contained HTML report

No server at all — a CLI runs the ablation matrix and emits a polished static HTML report (charts, per-query traces) you can commit to the repo, like faithfulnessbench does. Zero deploy, perfect reproducibility, but no live "type a query" moment.
